# FAKE POD NANO PRO（ESP32-S31）V1 量产版开发者硬件说明

**简体中文** | [English](hardware_v1_EN.md)

本文提供 V1 量产版的板载外设连接和开发参考参数，供购买设备后自行编写固件的用户使用。

所有引脚编号均为 ESP32-S31 的 **GPIO 编号**，不是芯片封装脚号或屏幕排线脚号。信号方向以主控为参照。本文仅适用于硬件版本 **1（V1 量产版）**。

## 1. 硬件概览

| 项目 | 参数 |
| --- | --- |
| 主控 | ESP32-S31 |
| ESP-IDF 目标名称 | `esp32s31` |
| 显示屏 | AMOLED，CO5300 控制器，QSPI 接口 |
| 可视分辨率 | 460 × 460 像素 |
| 触摸控制器 | CST820，I²C 接口 |
| 电源管理 | AXP2101，I²C 接口 |
| 音频 DAC | CS43131，I²S 音频输入、I²C 控制 |
| DAC 板载晶振 | 24.576 MHz |
| 麦克风接口 | PDM |
| 惯性传感器 | QMI8658，I²C 接口 |
| 实时时钟 | PCF85063，I²C 接口 |
| 存储卡接口 | SDMMC，4-bit |
| 按键 | 一个独立 GPIO 按键、一个 AXP2101 电源按键 |

## 2. 显示屏 GPIO 与参数

| 信号 | GPIO | 方向 | 说明 |
| --- | --- | --- | --- |
| VCI_EN | 44 | 输出 | AMOLED 电源使能，高电平使能 |
| RESET | 36 | 输出 | 屏幕复位 |
| CS | 37 | 输出 | QSPI 片选 |
| SCK | 38 | 输出 | QSPI 时钟 |
| DATA0 | 39 | 数据线 | QSPI 数据线 0 |
| DATA1 | 40 | 数据线 | QSPI 数据线 1 |
| DATA2 | 42 | 数据线 | QSPI 数据线 2 |
| DATA3 | 43 | 数据线 | QSPI 数据线 3 |
| TE | 35 | 输入 | 屏幕刷新同步信号 |

| 开发参数 | 值 |
| --- | --- |
| 接口类型 | 4 线数据 QSPI，独立 CS 与 SCK |
| SPI 控制器参考选择 | SPI2 |
| SPI 模式 | Mode 0 |
| QSPI 时钟参考值 | 80 MHz |
| 像素格式 | RGB565，16 bit/pixel，RGB 顺序 |
| 显示窗口偏移 | X = 10，Y = 0 |
| 逻辑坐标范围 | X：0～459；Y：0～459 |
| 对应屏幕 RAM 窗口 | X：10～469；Y：0～459（含端点） |
| 一帧 RGB565 有效像素数据 | 423,200 字节（460 × 460 × 2） |

开发要点：

- 使用支持 CO5300 QSPI 协议的驱动；本接口没有独立 D/C GPIO。
- 显示窗口偏移必须用于每次设置绘制窗口，仅在初始化时设置一次不足以保证后续刷新位置正确。
- 上电时可先将 VCI_EN 拉低 10 ms，再拉高并等待 120 ms，随后执行屏幕复位和控制器初始化。完整初始化时序以屏幕模组要求为准。
- AMOLED 亮度通过控制器命令调节，VCI_EN 用于供电使能。
- TE 用于同步写屏；边沿选择应结合实际 TE 波形确定。
- 80 MHz 是开发参考配置，不代表任意接线长度下的保证值；外接排线改变后需重新验证。

## 3. I²C 总线与设备地址

### 总线连接

| 总线 | SDA GPIO | SCL GPIO | 时钟参考值 | 板载设备 |
| --- | --- | --- | --- | --- |
| I²C0 | 48 | 47 | 400 kHz | CST820、AXP2101、QMI8658、PCF85063 |
| I²C1 | 55 | 54 | 400 kHz | CS43131 |

### 设备地址

下表均为 **7-bit I²C 地址**，配置 ESP-IDF 驱动时直接使用，无需左移一位。

| 设备 | 总线 | 地址 | 用途 |
| --- | --- | --- | --- |
| CST820 | I²C0 | `0x15` | 触摸数据 |
| AXP2101 | I²C0 | `0x34` | 电源、充电、电池状态及电源按键 |
| PCF85063 | I²C0 | `0x51` | 实时时钟 |
| QMI8658 | I²C0 | `0x6B` | 加速度、角速度数据 |
| CS43131 | I²C1 | `0x30` | DAC 寄存器配置 |

同一总线上的设备共用 SDA/SCL。自行开发时应共用一个总线实例，并协调并发访问；不要为每个设备重复初始化同一组引脚。

## 4. 触摸 GPIO

| 信号 | GPIO | 方向 | 说明 |
| --- | --- | --- | --- |
| SDA | 48 | 双向 | 共用 I²C0 |
| SCL | 47 | 输出 | 共用 I²C0 |
| INT | 45 | 输入 | 触摸中断，低电平有效 |
| RESET | 46 | 输出 | 触摸复位，低电平有效 |

触摸逻辑坐标对应 460 × 460 显示区域。改变显示方向时，应同步处理触摸坐标的旋转或镜像。

## 5. 电源管理与按键

| 信号或按键 | GPIO / 连接 | 方向 | 说明 |
| --- | --- | --- | --- |
| PMU SDA | GPIO48 | 双向 | 共用 I²C0 |
| PMU SCL | GPIO47 | 输出 | 共用 I²C0 |
| PMU INT | GPIO49 | 输入 | AXP2101 中断；可使用下降沿触发后读取中断状态 |
| 下方独立按键 | GPIO61 | 输入 | 低电平按下，可配置上拉 |
| 上方电源按键 | AXP2101 电源按键输入 | — | 通过 PMU 读取按键事件，无独立主控 GPIO |

已明确的供电参数：

| 电源输出 | 电压 |
| --- | --- |
| AXP2101 DCDC1 | 默认 3.3 V |
| AXP2101 ALDO1 | 1.8 V |

自行编写固件时，应先完成 PMU 通信与所需电源输出配置，再初始化对应外设。上方电源按键的短按事件和长按开关机行为由 AXP2101 配置；读取事件后需按 PMU 要求清除中断状态。

本文未提供各电源轨的完整负载对应关系，不应仅凭输出名称调整其电压或开关状态。

## 6. 音频 DAC：CS43131

| 信号 | GPIO | 方向 | 说明 |
| --- | --- | --- | --- |
| BCLK / BCK | 52 | 输出 | I²S 位时钟 |
| LRCLK / WS | 51 | 输出 | I²S 左右声道时钟 |
| DIN | 50 | 输出 | 主控音频数据输出，接 DAC 数据输入 |
| RESET | 53 | 输出 | DAC 复位，初始化时可先拉低再拉高 |
| 控制 SDA | 55 | 双向 | I²C1，地址 `0x30` |
| 控制 SCL | 54 | 输出 | I²C1 |
| 主控 MCLK | 未分配 GPIO | — | DAC 使用板载 24.576 MHz 晶振 |

| 开发参考参数 | 值 |
| --- | --- |
| I²S 控制器 | I²S1，发送方向 |
| 主从关系 | 主控提供 BCLK 与 WS |
| 数据格式 | 标准 I²S（Philips），立体声，MSB first |
| 参考采样率 | 48 kHz |
| 参考有效数据位宽 | 24 bit |
| 参考声道时隙位宽 | 32 bit |
| 更高采样率参考值 | 96 kHz；需同步配置 DAC 时钟和 I²S |

在双声道、每声道 32-bit 时隙配置下，BCLK = 采样率 × 2 × 32：48 kHz 对应 3.072 MHz，96 kHz 对应 6.144 MHz。

DAC 的控制接口和音频数据接口需要分别初始化。24-bit 有效数据与 32-bit 时隙是不同参数，配置时应同时检查数据对齐和 DAC 接口格式。96 kHz 是开发参考值，不表示 CS43131 芯片的规格上限。

## 7. PDM 麦克风

| 信号 | GPIO | 方向 | 说明 |
| --- | --- | --- | --- |
| PDM DATA | 2 | 输入 | 麦克风数据 |
| PDM CLK | 6 | 输出 | 主控提供 PDM 时钟 |

麦克风使用 I²S0 的 PDM 接收功能，与 DAC 使用的 I²S1 区分。应使用 PDM 接收配置，不能按普通 I²S 的 BCLK/WS/DIN 三线接口配置。本文未指定麦克风料号、声道选择电平及额定 PDM 时钟范围。

## 8. SDMMC 存储卡

| 信号 | GPIO | 方向 |
| --- | --- | --- |
| D0 | 20 | 双向 |
| D1 | 21 | 双向 |
| D2 | 22 | 双向 |
| D3 | 23 | 双向 |
| CLK | 24 | 输出 |
| CMD | 25 | 双向 |

- 接口为 4-bit SDMMC，工作时钟参考值为 40 MHz。
- 开发参考配置不使用 UHS 模式。
- 初始化时由 SDMMC 驱动完成低速识别，再切换到工作时钟。
- 本文未提供独立的卡检测 GPIO；插卡状态可先通过驱动初始化和访问结果判断。

## 9. IMU 与 RTC

QMI8658 与 PCF85063 均连接 I²C0，无需额外分配 SDA/SCL。

| 设备 | 开发说明 |
| --- | --- |
| QMI8658 | 地址 `0x6B`；可读取加速度和角速度；本文未提供其 INT 引脚到主控的连接，可先使用寄存器轮询方式 |
| PCF85063 | 地址 `0x51`；首次上电或振荡停止后，应检查时间有效性并重新校时；本文未提供其 INT/CLKOUT 到主控的连接 |

## 10. 自行开发前的参数确认

开发环境需支持 `esp32s31` 目标。以上 GPIO 和外设参数用于建立自己的板级配置，不依赖预装应用。

Flash/PSRAM 的实际容量与型号、USB 数据线连接、下载模式操作、屏幕尺寸及排线脚序、电池规格和电源轨负载关系未在本文中确定。涉及这些项目时，请以对应量产批次的实物标识、原理图或补充规格为准。

表中 GPIO 已连接板载外设；未列出的 GPIO 也不能据此认定为可用扩展引脚。
